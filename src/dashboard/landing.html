Hearth

Your computer as a local-first AI software engineering runtime, exposed to ChatGPT, Claude, and other MCP-compatible clients. You run the server, the execution environment, and the workspace authority.

Install

Install once, then hearth works like opencode:

npm install -g @sunshinelife83/hearth
hearth init
hearth serve

Then hearth connect prints per-host steps, and hearth doctor checks Node, Git, Bash, URLs, and hosts.

From a source checkout: ./install.sh, then hearth init. Requires Node 22.19+.

Use it

  1. Run hearth serve (or hearth mcp for local stdio).
  2. Open the local dashboard and sign in with your Owner password.
  3. Run hearth connect and paste the public /mcp URL into your MCP client (via your own tunnel for remote clients).
  4. Ask it to open a project, plan a task, delegate to a coding agent, verify, land.

Connect

Each PC has a stable hearth-xxxx diagnostic label (hearth id). Keep one public URL per PC — OAuth tokens are bound to that machine's resource URL. The label is not a security boundary: copying the state directory copies the identity.

  • ChatGPT: add the public /mcp URL as a connector, approve with the Owner password.
  • Claude: same public /mcp URL; ensure oauth.allowedRedirectHosts includes claude.ai. Or hearth token create claude-local + hearth mcp for local stdio.
  • Any MCP client: remote OAuth via public /mcp, or local hearth mcp with a device token bearer.

Tip: hearth connect chatgpt|claude|generic prints the exact snippet for this machine. /healthz reports this machine's id and MCP URL.
